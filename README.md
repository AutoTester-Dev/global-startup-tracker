# Global Startup & Funding Tracker 🚀

An advanced automated web scraping utility designed to track emerging tech startups, venture capital funding rounds, and industry insights, neatly exporting structured intelligence into professional Excel spreadsheets.

## 🛠️ Tech Stack
- **Python** (Core backend)
- **Requests** (HTTP request management with custom User-Agent headers)
- **BeautifulSoup** (HTML DOM parsing and targeted content extraction)
- **Pandas & OpenPyXL** (Data manipulation and executive-level Excel styling)

## 📌 Features
- Extracts real-time startup news, funding announcements, and summaries from tech directories.
- Automatically structures raw unstructured articles into clean tabular data.
- Generates an executive-ready Excel report (`startups_funding_data.xlsx`) featuring custom dark navy headers, thin cell borders, auto-adjusted column widths, and dynamic row wrapping to eliminate text compression.
